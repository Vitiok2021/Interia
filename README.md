
# Interia

## Опис
Лендінг для студії інтер'єрного дизайну. Сучасний дизайн, адаптивна верстка, слайдери, анімації. Це простий та стильний сайт для демонстрації послуг компанії з дизайну інтер'єрів.

## Технології
- HTML5
- SCSS
- JavaScript (без фреймворків)
- Адаптивна верстка (Flex, Grid)
- Слайдери та анімації для кращої взаємодії з користувачем.
